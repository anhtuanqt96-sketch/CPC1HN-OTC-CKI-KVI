Số liệu theo kỳ đang chọn ở trên (ngày/tuần/tháng), so sánh với kỳ liền trước. Nhận xét đánh giá được dashboard tự phân tích theo quy tắc dựa trên số liệu — không phải do một mô hình AI ngoài tạo ra.

Phân tích chuyên sâu bằng AI thật (Claude) dựa trên số liệu thật của dashboard — tìm nguyên nhân, cơ hội và kế hoạch hành động cụ thể, theo đúng khung phân tích của Trưởng nhóm.
CÀI ĐẶT Kết nối AI (Google Gemini API — miễn phí)
Dùng Google Gemini API — miễn phí, không cần thẻ thanh toán. Lấy API key tại aistudio.google.com/apikey (đăng nhập bằng tài khoản Google, bấm "Create API key", copy chuỗi bắt đầu bằng "AIza..."). Gói miễn phí giới hạn khoảng 15 yêu cầu/phút và ~1.500 lượt/ngày — nếu bấm "Chạy phân tích AI" liên tục nhiều lần trong thời gian ngắn có thể bị báo lỗi giới hạn tốc độ, chỉ cần đợi một chút rồi thử lại. API key chỉ được lưu trên trình duyệt này (localStorage) và gửi thẳng tới máy chủ Google — không đi qua máy chủ nào khác; không nên dùng chung máy/trình duyệt với người khác sau khi đã lưu key. Lưu ý về quyền riêng tư: với gói miễn phí, Google có thể dùng dữ liệu bạn gửi (bao gồm tên nhân viên/khách hàng, số liệu doanh số) để cải thiện sản phẩm của họ — nếu đây là dữ liệu nhạy cảm, cân nhắc ẩn bớt tên thật trước khi phân tích, hoặc chuyển sang dùng Anthropic Claude API (trả phí, không dùng dữ liệu để huấn luyện) nếu cần riêng tư hơn. Kỳ số liệu dùng đúng theo bộ lọc "Ngày xem / Kỳ báo cáo" đang chọn ở trang Tổng quan.
